# 任务列表规格

## S1 排序必须保持

`sort_tasks` 按 `priority` 从高到低排列。`priority` 相同的时候按 `name` 升序。函数返回新列表，不修改传入的列表。这项行为已经存在，后续修改不能把它改掉。

## S2 按状态筛选

`filter_tasks(tasks, status)` 只留下 `status` 字段与参数完全相同的任务，并保持传入列表里的相对顺序。

`status` 是 `None` 或空字符串时，返回全部任务，顺序不变。没有命中的状态返回空列表，不抛异常。函数返回新列表，不修改传入的列表。

"""功能测试：按状态筛选。修改前因为函数还没实现而失败。"""

import unittest

from sample_app.tasks import filter_tasks


class FilterTasksTest(unittest.TestCase):
    def test_filter_exact_status(self) -> None:
        tasks = [
            {"name": "a", "priority": 2, "status": "open"},
            {"name": "b", "priority": 1, "status": "done"},
        ]
        result = filter_tasks(tasks, "open")
        self.assertEqual([item["name"] for item in result], ["a"])

    def test_blank_status_returns_all_in_order(self) -> None:
        tasks = [
            {"name": "a", "priority": 2, "status": "open"},
            {"name": "b", "priority": 1, "status": "done"},
        ]
        self.assertEqual(filter_tasks(tasks, None), tasks)
        self.assertEqual(filter_tasks(tasks, ""), tasks)

    def test_unknown_status_returns_empty(self) -> None:
        tasks = [{"name": "a", "priority": 1, "status": "open"}]
        self.assertEqual(filter_tasks(tasks, "archived"), [])

    def test_filter_does_not_mutate_input(self) -> None:
        tasks = [
            {"name": "a", "priority": 1, "status": "open"},
            {"name": "b", "priority": 1, "status": "done"},
        ]
        filter_tasks(tasks, "done")
        self.assertEqual([item["status"] for item in tasks], ["open", "done"])


if __name__ == "__main__":
    unittest.main()

"""回归测试：排序行为必须保持。"""

import unittest

from sample_app.tasks import sort_tasks


class SortTasksTest(unittest.TestCase):
    def test_sort_priority_then_name(self) -> None:
        tasks = [
            {"name": "b", "priority": 1, "status": "open"},
            {"name": "a", "priority": 2, "status": "done"},
            {"name": "c", "priority": 1, "status": "open"},
        ]
        result = sort_tasks(tasks)
        self.assertEqual([item["name"] for item in result], ["a", "b", "c"])

    def test_sort_does_not_mutate_input(self) -> None:
        tasks = [
            {"name": "b", "priority": 1, "status": "open"},
            {"name": "a", "priority": 2, "status": "done"},
        ]
        sort_tasks(tasks)
        self.assertEqual([item["name"] for item in tasks], ["b", "a"])


if __name__ == "__main__":
    unittest.main()
