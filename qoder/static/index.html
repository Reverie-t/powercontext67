关于科研周报助手

功能介绍

科研周报助手是一个面向科研人员的工作台工具，帮助管理分散的实验记录、文献阅读、问题与待办，并自动生成有出处、可修改、可导出的周报。

核心特性

  • 真实记忆持久化：使用 PowerContext 1.4.1 存储项目偏好、研究记录和待办事项，支持跨会话、跨服务重启读取
  • 项目隔离：每个研究项目独立的 scope，记忆互不干扰
  • 按周生成周报：选择日期范围，自动整理本周记录和历史待办
  • 任务完成与偏好更新：已完成的任务不再进入后续周报；偏好修订后立即生效
  • 可编辑导出：周报支持 Markdown 编辑和导出
  • 记忆证据透明：清晰展示 PowerContext 的读写引用

生成模式说明

当前版本使用规则模式生成周报，不调用大语言模型：

  • 自动应用：量化结果优先排序（当偏好包含"量化"或"结果"时）
  • 人工参考：其他自由文本偏好（语言、风格等）显示在周报中供人工检查
  • 不声称自动翻译、智能总结或语义理解

技术栈

  • 后端：Python 3.11 + FastAPI + PowerContext 1.4.1
  • 存储：SQLite（PowerContext 内置）+ JSON（业务数据）
  • 前端：原生 HTML/CSS/JavaScript

运行说明

本地运行需要 Python 3.11+，安装依赖后执行：

qoder/.venv/Scripts/python.exe qoder/src/server.py

访问 http://127.0.0.1:8000

可指定独立数据目录：

set RESEARCH_WEEKLY_DATA_DIR=C:\path\to\data
qoder/.venv/Scripts/python.exe qoder/src/server.py
